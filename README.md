# QuizKZ Live

Мектеп мұғалімдері мен оқушыларға арналған нақты уақыттағы сынып-ішілік викторина, командалық жарыс (**Space Race**), жылдам сұрау (**Quick Question**), шығу билеті (**Exit Ticket**), дауыс беру (**Vote**), прокторинг және есеп беру платформасы.

## Негізгі мүмкіндіктер

- **Оқушылар аккаунтсыз кіреді**: телефон, планшет немесе ноутбуктен бөлме атауы немесе QR-код арқылы кіру, интернет үзілсе де жауапты жергілікті кезекте сақтап қайта жіберу.
- **5 тірі белсенділік**: Викторина (3 қарқын режимі), Space Race (Зымыран / Велосипед / Ара, 2–10 команда), Жылдам сұрақ, Шығу билеті, Дауыс беру.
- **Тірі басқару және Проектор режимі**: Server-Sent Events (SSE) + 2 секундтық polling резерві, анонимді толық экранды проектор көрінісі, қысқа жауаптарды қолмен бағалау.
- **Кітапхана және Редактор**: қалталар, бөлісу коды (`QZ-XXXXXX`), жария сілтеме, біріктіру, 30 күндік себет, авто-сақтау, Undo/Redo, KaTeX формулалары (`$...$`, `$$...$$`), сурет жүктеу (≤2 МБ).
- **Импорт және Экспорт**: Word (`.docx`), Excel (`.xlsx`), PDF, TXT/CSV импорттау; Excel (4 парақ), Word (жауап кілтімен / кілтсіз), PDF/A4 баспа және CSV экспорттау.
- **Прокторинг**: толық экран бақылауы, қойынды ауыстыруды есептеу, көшіру/қоюды шектеу, лимит кезінде журналға жазу немесе автоматты аяқтау.
- **Қосымша Gemini AI**: `GEMINI_API_KEY` берілсе құжаттан сұрақ тану, тақырып бойынша сұрақ генерациясы, сұрақты өңдеу және сынып есебін талдау іске қосылады. Кілт болмаса, AI батырмалары өшірулі тұрып, бүкіл қалған функционал мінсіз жұмыс істейді.
- **Тілдер мен Тақырып**: Қазақша (әдепкі), Орысша, Ағылшынша; жарық және қараңғы режим.

## Жергілікті іске қосу

```bash
npm install
cp .env.example .env
npm run dev
```

Қосымша әдепкі бойынша `http://localhost:3000` мекенжайында ашылады.

### Өндірістік құрастыру және іске қосу

```bash
npm run lint
npm run build
NODE_ENV=production PORT=8080 AUTH_SECRET="your-strong-secret" npm start
```

## Орта айнымалылары

| Айнымалы | Әдепкі | Сипаттама |
|---|---|---|
| `PORT` | `3000` | Сервер порты (`0.0.0.0` бойынша тыңдайды) |
| `DATA_DIR` | `./data` | `quizkz-store.json` және `backups/` қалтасы сақталатын жол |
| `AUTH_SECRET` | — | HMAC токен қолтаңбасының құпия кілті (production-да міндетті түрде орнатыңыз) |
| `GEMINI_API_KEY` | — | Міндетті емес. Gemini AI мүмкіндіктерін қосу үшін |
| `APP_URL` | — | Қоғамдық URL (сілтемелер мен QR-кодтар үшін) |

## Render.com платформасына орналастыру

1. Жобаны GitHub репозиторийіне жүктеңіз.
2. Render консолінде **New → Blueprint** таңдап, осы репозиторийді қосыңыз (`render.yaml` автоматты оқылады).
3. `AUTH_SECRET` автоматты генерацияланады, `/data` дискісі қосылады, `/healthz` тексерісі іске қосылады.
4. Қаласаңыз `GEMINI_API_KEY` айнымалысын Environment бөлімінде қосыңыз.

## Жоба құрылымы

- `server.ts` — Express API, SSE ағындары, импорт/экспорт, AI бағыттары және Vite/статика қызметі.
- `server/store.ts` — Атомарлы JSON сақтау, жазу кезегі, `schemaVersion` миграциясы және түнгі резервтік көшірмелер.
- `server/scoring.ts` — Автоматты/жартылай/қолмен балдау және есеп статистикасы.
- `server/sessions.ts` — Тірі сессия күйі, SSE хабы, `seq` буфері, таймерлер және 6 сағаттық авто-жабу.
- `server/auth.ts` — `crypto.scrypt` хэштеу, HMAC токендер, оқушы токендері және IP rate limiter.
- `server/importers.ts` & `server/exporters.ts` — DOCX/XLSX/PDF/TXT импорттау және XLSX/DOCX/CSV экспорттау.
- `server/ai.ts` — Серверлік `@google/genai` интеграциясы.
- `src/components/teacher/*` — Мұғалім мен әкімші интерфейсінің барлық бөлімдері.
- `src/components/student/*` — Оқушының мобильді-бірінші экрандары.
- `src/components/shared/*` — KaTeX мәтін рендері, SVG графиктер, модальдар, тосттар, QR-код.
